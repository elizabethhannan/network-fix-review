- All data is simulated and seeded (`mulberry32`), so every dashboard number comes from one record set plus the viewer's decisions. Keep tiles, chart, lists and requirements computed from the same records.
- Views: Review (`#review`), What the model learns (`#learn`), Telemetry spec (`#spec`).
- Keep the "Simulated network · example data" and "Self-initiated concept" labels visible.
- HXO appears only as its name and core sentence, word for word.
- Accessibility: keyboard paths for tabs and charts, never color alone, light and dark themes.
